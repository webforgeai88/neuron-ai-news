# Нейрон — новости мира ИИ

Учебный проект для портфолио: новостной сайт с рабочей редакцией и тремя ролями.

**Работающий сайт:** https://neuron-ai-news.shrewd-snipe-3626.chatgpt.site/

Сайт открыт для посетителей без входа в ChatGPT. Для проверки функций нажмите «Попробовать админ-панель» на главной. Регистрация не нужна; создаётся отдельная тестовая копия.

## Возможности

- Читатель: поиск, категории, отдельные статьи и первоисточники.
- Сотрудник: создание, редактирование, черновики, публикация и загрузка обложек.
- Администратор: управление публикациями и сотрудниками.
- Личная тестовая редакция с переключением ролей и сбросом изменений.
- 15 новостей с индивидуальными ИИ-иллюстрациями.
- Адаптация для телефонов, планшетов, ноутбуков и широких экранов.

## Проверка для преподавателя

1. Откройте сайт и нажмите «Попробовать админ-панель».
2. Выберите администратора.
3. Создайте новость, сохраните черновик, затем нажмите «Опубликовать».
4. Откройте ленту и проверьте материал.
5. В разделе сотрудников создайте тестовый аккаунт и проверьте его вход.
6. Сравните права сотрудника и администратора. Все изменения изолированы от основной ленты.

## Технологии

React 19, TypeScript, Vinext/Vite, Supabase Postgres, Auth, Storage и Edge Functions. Текущая публикация работает на Sites/Cloudflare Workers.

## Локальный запуск

Требуется Node.js 22.13 или новее. Выполните npm ci, скопируйте .env.example в .env.local и заполните собственные значения. Запустите npm run dev. Сборка: npm run build.

Для собственной базы примените SQL из supabase/schema.sql и supabase/access.sql, настройте bucket neuron-covers и разверните функцию supabase/functions/neuron-api. Привилегированный ключ остаётся только в серверной среде Supabase. Общий секрет прокси хранится в серверных переменных, а его SHA-256 — в neuron_settings.

Переменные среды и пароли не входят в репозиторий. GitHub Pages сам по себе не запускает серверную часть этого проекта: для собственного размещения нужен совместимый серверный хостинг.

## Проверки

Проверены роли, изоляция тестовых редакций, создание и публикация новостей, загрузка изображений и отзыв доступа. Проверяемые ширины: 390, 768, 1024, 1366, 1920, 2560 пикселей.

Материалы — редакционные пересказы указанных первоисточников. Изображения созданы с помощью ИИ. Проект не является официальным изданием упомянутых компаний.
